# Правила библиотеки и композиции

Это то, что сервис обязан соблюдать автоматически. Каждое правило ниже должно
быть проверкой в коде, а не договорённостью.

## Библиотека компонентов (слова заказчика)

- Иллюстрации делятся на 2 размера. Разница в детализации. Конструктор даёт выбор
  размера и автоматически подгружает соответствующие элементы.
- Сейчас существует 3 цветовые схемы, в будущем их может стать больше.
- Есть главные объекты (цветные) и фоновые (монохром). В зависимости от смысла
  или композиции фоновые объекты можно использовать или не использовать.
- Цвета фонов могут использоваться в объектах. Цвета для объектов не могут
  использоваться в фонах.

## Можно

- менять композицию и расположение объектов;
- менять состояние объекта: главный или фоновый;
- менять цвета объекта.

## Нельзя

- менять пропорции объектов относительно друг друга;
- менять сам объект и его элементы (объект по сути просто копируется);
- нарушать цветовую схему.

## Что из этого следует для сервиса

| Правило | Как соблюдается |
|---|---|
| Пропорции объектов относительно друг друга | Масштаб один на всю композицию. У отдельного объекта ручки масштаба нет: только перенос, поворот, дубль, удаление, порядок слоёв. |
| Объект не меняется | Геометрия берётся из библиотеки как есть. Редактор меняет только `transform` экземпляра и значения цветов. Правки путей нет. |
| Цветовая схема не нарушается | Цвета объекта хранятся ролями (токенами), а не hex-значениями. Перекраска - замена таблицы "роль -> цвет". Произвольный цвет выбрать нельзя. |
| Цвета объектов не идут в фон | У схемы два набора: фоновые цвета и объектные. Фон и фоновые объекты берут цвет только из первого, главные объекты - из обоих. |
| Главный или фоновый | У каждого объекта два варианта отрисовки: цветной и монохромный. Переключение меняет вариант, геометрия та же. |
| 2 размера | Библиотека хранит по два набора элементов. Выбор размера переключает набор целиком, смешивать наборы в одной композиции нельзя. |
| Новые схемы | Схема - файл данных. Добавление схемы не требует правки кода. |
| Только вектор | Экспорт собирает SVG из исходных узлов библиотеки. Растра в цепочке нет нигде. |

## Не выяснено

- Что такое "2 размера": два уровня детализации одного объекта или два формата холста.
  В примерах форматов холста два (1000x1000 и 800x1200), и это может быть отдельная ось.
  Нужно посмотреть в Figma, как названы варианты компонентов.
- В ТЗ 20 исходных иллюстраций, в примерах 12 (6 сюжетов в двух форматах). Остальные - в Figma.
- В каком виде загружается палитра (как это делает плагин в Figma): список цветов, JSON, стили Figma.
- Точные значения цветов трёх схем. В примерах видна одна схема.
