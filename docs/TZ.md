## Задача

Разработать веб-сервис, который позволяет из отдельных компонентов (это отдельные
иллюстративные объекты, из которых собираются иллюстрации) собирать различные
комбинации композиций для иллюстраций в разных форматах.

Процесс должен быть автоматизирован.

Сценарий 1: человек задаёт метафору или заголовок, а программа сама собирает
подходящие объекты в композицию.

Сценарий 2: человек вбивает названия нужных компонентов, которые далее компонуются
в композицию.

## Ключевое ограничение

Сервис не генерирует новые объекты: итоговая композиция состоит только из элементов
исходных 20 иллюстраций. AI-инструменты разрешены для разработки самого сервиса и
анализа метафор. Объекты никак не меняются, итоговая композиция - в векторном формате.

Не обязательно разрабатывать отдельный сайт или приложение. Это может быть плагин
для Figma: вся библиотека и компоненты существуют в Figma.

## Что должен уметь сервис

### 1. Работа с SVG и библиотекой элементов

- загружать или использовать заранее подготовленную библиотеку из SVG-иллюстраций;
- корректно сохранять векторную структуру, цвета и пропорции элементов.

### 2. Сборка композиции

- добавлять элементы из библиотеки на общий холст;
- перемещать, поворачивать, дублировать и удалять объекты;
- управлять порядком слоёв и собирать сцену из элементов нескольких исходных иллюстраций;
- давать выбор размера и цветовой схемы.

### 3. Работа с цветовой палитрой

Не просто сохранять цвета элементов: загрузка цветовой палитры в сервис и
автоматическая перекраска композиции (как это сейчас делает плагин в Figma).

### 4. Экспорт

- скачивать итоговую композицию в формате SVG;
- сохранять векторность и редактируемость объектов, не превращая результат
  в растровое изображение.
