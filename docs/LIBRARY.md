# Опись объектов по примерам

Снято глазами с 12 PNG в `examples/`. Файл Figma не читался, поэтому названия
объектов рабочие, а не из библиотеки. После доступа к Figma опись заменить
на реальные имена компонентов и выгрузить SVG в `library/`.

## Объекты

| Объект | Как главный (цветной) | Как фоновый (монохром) |
|---|---|---|
| Книга с закладкой | book-phone | book-puzzle-pen |
| Телефон с пазлом на экране | book-phone, phone-puzzle | - |
| Пазл из двух деталей | phone-puzzle, book-puzzle-pen | - |
| Наушники | headphones-vase | - |
| Ваза (со стеблями или тюльпанами) | - | headphones-vase |
| Папка с документами | folder-wallet-coin | - |
| Кошелёк | folder-wallet-coin, wallet-coin-lamp | - |
| Монета с замком | folder-wallet-coin, wallet-coin-lamp | - |
| Ручка | book-puzzle-pen | - |
| Цилиндр на подставке | - | wallet-coin-lamp |

Мелкие фоновые детали: тонкие диагональные линии, овальные пятна, полоса другого
тона в правом нижнем углу.

## Что видно про правила

- Книга встречается в обоих состояниях: цветная в book-phone и монохромная
  в book-puzzle-pen. Геометрия та же, меняется только набор цветов.
- Кошелёк перекрашен внутри одной схемы: сиреневый с жёлтой картой
  в folder-wallet-coin, жёлтый с розовой картой в wallet-coin-lamp.
- В двух форматах одного сюжета объекты те же, меняется раскладка и кадрирование.
  В 800x1200-headphones-vase ваза с тюльпанами, в 1000x1000 - со стеблями:
  либо разные объекты, либо другое кадрирование. Проверить в Figma.
- Главные объекты: чёрный контур, заливки белым, жёлтым, розовым, фиолетовым,
  плотная чёрная тень. Фоновые: контур и заливки только в оттенках фона.

## Цвета в примерах

Одна схема: сиреневый фон, фиолетовый, светло-фиолетовый, жёлтый, розовый,
чёрный, белый. Hex-значения не снимались, брать из стилей Figma.
